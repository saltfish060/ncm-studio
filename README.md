# NCM Studio

Windows 本地音频工具：把网易云音乐下载的 `.ncm` 文件转换为 MP3 / FLAC。完全在本机运行，支持拖放、批量转换、自动查找下载目录，以及输出格式、命名与整理方式的自定义。

## 特色功能

- **高度美观的现代化 UI**：基于 Electron + React + CSS 定制
- **全本地运行**：不联网、不上传，任何音频数据都不会离开你的电脑
- **自动跟随源格式**：默认不做多余转码——`.ncm` 里封装的是 MP3 就输出 MP3，是无损就保持无损；需要统一格式时可以手动指定 MP3 或 FLAC
- **自动寻歌**：自动检索常见下载位置和注册表里记录的下载目录，并在每个磁盘的前三层寻找 `CloudMusic` / 网易云音乐 / `VipSongsDownload` 一类文件夹；你手动选过的目录会被记住，下次一起搜索
- **保留歌曲信息**：标题、歌手、专辑会写入输出文件，跨格式转换同样保留
- **批量与可控**：一次拖入多个文件，逐个显示进度与状态，任务可随时停止
- **输出规则自由**：MP3（320 / 256 / 192 / 128 kbps）或 FLAC；文件名支持 `{title}`、`{artist}`、`{album}`、`{filename}`；遇到重名可自动加序号、覆盖或跳过
- **自动归档**：按「歌手 / 专辑」两级目录整理输出
- **转换记录**：按「上一次转换」分组标记，一眼看到最近一次转了什么
- **不会自我循环**：自动跳过输出目录，不会把转换结果再当成待转换文件扫回来
- **开箱即用**：免安装便携版，支持拖放添加文件，深浅色主题跟随系统

## 快速开始

1. 打开程序，把 `.ncm` 文件拖进窗口（也可以点「添加文件」；不确定文件在哪就点「自动查找」）
2. 在「设置」里选输出格式和保存位置（格式默认「自动」，跟随源文件；保存位置默认 `音乐\NCM Studio`）
3. 回到「转换列表」点「开始转换」，完成后可在「转换记录」里回看

## 小提示

- **默认不做二次转码**：输出格式默认是「自动」，`.ncm` 里是什么格式就输出什么格式——速度接近瞬时，也不会产生二次压缩损失。想把结果统一成 MP3 或 FLAC，在设置里选对应项即可。
- **找不到文件**：自动查找会检查常见位置、注册表记录的下载目录，以及每个磁盘前三层的目录；音乐放在很深的路径里时，用「手动选择文件夹查找」，这个目录会被记住，以后一起搜索。
- **封面图**：跨格式转换（例如 MP3 转 FLAC）会保留标题、歌手、专辑，但不会带上内嵌封面图；同格式直出时封面保持原样。
- **重名文件**：默认自动加序号，也可以在设置里改成覆盖或跳过。

## 系统要求

- Windows 10 / 11（64 位）
- 免安装：下载便携版 exe，双击即可运行

## 开发运行

```powershell
npm install
npm run dev
```

## 构建 Windows 安装包

```powershell
npm run build
```

构建产物位于 `release` 文件夹。
